# Asteroids

A clone of the classic arcade game Asteroids, built using Python and Pygame.

## Description

This project was built as part of the Boot.dev backend curriculum. Players control a spaceship navigating through a field of asteroids, rotating, accelerating, and shooting lasers to destroy hazards while avoiding collisions.

## Features

- 2D player-controlled spaceship with rotation and movement
- Wrap-around or bounded play area
- Asteroid generation with splitting mechanics upon destruction
- Shooting and collision detection systems

## Requirements

- Python 3.10+
- [Pygame](https://www.pygame.org/)

## How to Play

1. Run the game using Python:
   ```bash
    python3 main.py

2. Controls:

W / Up Arrow: Move forward
A / Left Arrow: Rotate left
S / Down Arrow: Move backwards
D / Right Arrow: Rotate right
Spacebar: Shoot
